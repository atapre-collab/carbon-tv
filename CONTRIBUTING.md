# Contributing

Use a small branch and explain the problem, the resulting behavior and how you tested it. Keep changes compatible with remote navigation and the existing matte interface.

Run the source tests and Android build before submitting. Include the TV model, Android version and whether the issue also occurs without external services. Remove identifiers, account details, stream tokens and API keys from logs and screenshots.

Do not contribute subscription bypasses, scraped private account data, unlicensed media, credentials or proprietary firmware. Integrations should use documented interfaces and communicate their limitations accurately.

For UI changes, include screenshots and check long text, focus outlines, Back behavior, and lower-resolution displays. For AI changes, test cancellation and ensure a stale response cannot launch an app after the user leaves.
